# Snap2Skill delivery outcomes

## Single-screen studio shell and visual system
- [ ] The app uses a responsive single-screen workspace with a minimalist Snap2Skill header, project branding, and live status badge “⚡ Gemma 4 Active”.
- [ ] The app uses only the requested palette: #09090b canvas, #18181b surfaces, #27272a borders, #6366f1 accent, #fafafa primary text, and #a1a1aa secondary text.
- [ ] Cards use rounded-xl corners, crisp borders, and polished micro-interactions without chaotic page scrolling.

## Sketch input and compile state machine
- [ ] The left 40% column contains a dashed-border dropzone for process sketches, whiteboard photos, and notebook flowcharts.
- [ ] “⚡ Load Sample Sketch” instantly preloads a test flowchart.
- [ ] “Compile to Skill” moves through Idle → Uploading → Compiling with clear loading feedback → Success Studio.

## Output studio
- [ ] The right 60% column exposes reliable tabs for Visual Flowchart, SKILL.md Spec, and Live Sandbox.
- [ ] Visual Flowchart clearly renders the detected workflow structure.
- [ ] SKILL.md Spec presents standard-compliant generated markdown with one-click copy and copy feedback.
- [ ] Live Sandbox supports interactive chat messages and context-aware responses for the compiled skill.
